# IoTE Web Application development
**Web Application for IoT & Information Engineering**

เว็บนี้เราพัฒนาเพื่อเปลี่ยนจากเว็บเดิมที่ให้แค่ข้อมูลไปเป็นเว็บภาควิชาที่ใช้ประโยชน์ได้จริง ใช้งานง่ายทั้งบุคคลทั่วไป นักศึกษา และอาจารย์

---

## Features!

เว็บนี้ได้รับการพัฒนาและอัปเดตฟีเจอร์ใหม่ 6 ส่วน เพื่อตอบโจทย์การใช้งานอย่างรอบด้าน

1. **ระบบประกาศข่าวสาร (News & Announcements)** 
   ติดตามข่าวสารสำคัญของภาควิชา ทุนการศึกษา และประกาศฉุกเฉินได้ในที่เดียว
2. **ปฏิทินกิจกรรม (Event Calendar)** 
   ระบบปฏิทินที่รวบรวมกำหนดการสำคัญ เช่น วันสอบ workshop และกิจกรรมของภาควิชา
3. **คลังความรู้ (Knowledge Hub)** 
   ศูนย์รวมเอกสารประกอบการเรียน สไลด์สอน และแหล่งอ้างอิงทางเทคนิคสำหรับนักศึกษา
4. **แหล่งรวมประสบการณ์ฝึกงาน (Internship Experience Hub)** 
   พื้นที่อ่านและแบ่งปันรีวิวบริษัท สภาพแวดล้อมการทำงาน และคำแนะนำการสัมภาษณ์จากรุ่นพี่
5. **ข้อเสนอแนะอาจารย์แบบ Real-Time (Real-Time Feedback)** 
   ช่องทางการสื่อสารที่ทำให้นักศึกษาสามารถส่งข้อเสนอแนะหรือสอบถามอาจารย์ผู้สอนได้ทันที
6. **วางแผนการลงทะเบียนเรียน (Course Registration Planner)** 
   เครื่องมือช่วยจำลองการจัดตารางเรียนและวางแผนหน่วยกิต

- **Backend:** PHP
